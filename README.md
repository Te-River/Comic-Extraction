# Comic-Extraction · 漫画归档

引导 Agent 依据你提供的线索，定位并抓取**国内可直接访问**的漫画汉化版本——页面图、正文文本，以及存在时的原作小说——按统一规范归档到本地，供留存、追更与阅读器使用。

> 本仓库是**规范与档案仓库**，不是素材仓库。
> 抓取下来的图片与正文体积大、且属第三方作品，一律只存本地、不入库（见下方「为什么仓库里没有漫画」）。

---

## 仓库里有什么

| 文件 | 作用 |
|---|---|
| [`Agent.md`](Agent.md) | **权威作业手册**。给 Agent 读：命名规范、作业流程、增量追更、档案模板、交付校验清单 |
| `LICENSE` | Apache License 2.0 |
| `[xxxxxxxx]漫画名称——作者/` | **演示项目**，展示标准目录结构。其中图片与文本是 0 字节占位文件，不是真实素材 |

`Agent.md` 是这个项目的唯一规范来源。改规则请改它，别在别处另立规矩。

## 为什么仓库里没有漫画

`.gitignore` 排除了全部归档素材（`jpg` / `png` / `webp` / `txt` / `epub` / `cbz` 等），只保留规范文档与演示结构。两个原因：

1. **素材是第三方作品**，公开仓库不适合承载。
2. **git 历史无法真正删除已推送的大文件**。单张漫画页可达十几 MB，一次归档就是几百 MB；一旦入库，体积会随每次追更永久累积，且无法干净清除。

素材就放在你本地的这个目录里，不进版本库。演示项目是例外：它的 0 字节占位文件没有体积也没有版权问题，同时充当命名约定的活文档。

## 目录与命名规范（简版）

一部漫画 = 一个文件夹：

```
[xxxxxxxx]漫画名称——作者
```

| 组成 | 规则 |
|---|---|
| `xxxxxxxx` | 该漫画**最近一次成功运行的结束日期**，8 位无分隔符。2026-06-11 → `20260611` |
| `漫画名称` | 通行中文名 |
| `——` | 两个 `U+2014 EM DASH`（不是 `U+2015`，不是 `--`） |
| `作者` | 查不到就写 `未知作者`，不编造 |

目录内部：

```
[20260611]漫画名称——作者\
├─ Agent.md          该漫画的独立档案：来源、版本、已归档范围、追更方法
├─ jpg\              图片目录，名字 = 实际扩展名，全小写
│  ├─ 第一章.jpg
│  └─ 番外\          非正篇
└─ txt\              文本目录，名字 = 实际扩展名，全小写
   └─ 第一章.txt
```

要点：

- 素材目录名**跟着实际抓到的格式走**。抓到 `.png` 就叫 `png/`，不存在「先建 jpg 再把 png 塞进去」。
- 章节排序必须先做**中文数字转数值**再排。字典序会把 `第十章` 排到 `第二章` 前面——这是阅读器最容易踩的坑。
- 日期前缀只在**本次运行确实产出并通过校验**时刷新；失败则保持原值不动。

完整规则见 [`Agent.md`](Agent.md)。

## 怎么用

1. 把漫画名、作者、已知链接等线索告诉 Agent
2. Agent 依 `Agent.md` 定位可直连的来源，抓取并按规范落盘
3. 每部漫画在自己的 `Agent.md` 里记下来源与追更方式
4. 之后追更只需说「更新 X」，Agent 读该漫画的档案即可只抓新增章节

Agent 只处理**公开可访问**的来源。遇到登录墙、付费墙会停下并告知，不绕过。
