# 基本信息
该项大类均为演示，请你自行规划并以你规划的写入项目根目录的Agent.md
以下是你需要记住的点
1.jpg文件夹内存放着你扒取下来的文件，需要注意的是该文件夹并非永远叫jpg，如果扒取下来的文件为.png后缀那么该文件夹也会改名为相应的后缀名（全小写）
2.txt文件夹内存放着你扒取下来的文本，需要注意的是该文件夹并非永远叫txt，如果扒取下来的文件为.edup后缀那么该文件夹也会改名为相应的后缀名（全小写）
3.该Agent.md将存放于每一个"[xxxxxxxx]漫画名称——作者"文件夹内，用于存储漫画信息，最后一次运行，后续如果更新该如何获取新版，目前的版本是如何获取这个漫画的文本与图源
