**XOR 方案（lead 亲自证明，可复现）**：
```
明文[i] = 密文[i] XOR drmHash[i % 8]      # drmHash 为 16 位十六进制 = 8 字节；整文件、从偏移 0
```
- 每页 `drmHash` **各不相同**，必须逐页取（见 viewer JSON 的 `manuscripts[].drmHash`）

3. `browser.files.list({tabID})` → `fileID`；`browser.files.get({tabID, fileID})` → **服务端本地路径**（字节不进上下文）
4. 收进 `webp/ja/001.第1話/NNN.webp`

### 文体与符号约定（逐字保持）
1. **`━━━`** 兼两用：独占一行的**场景分隔符**，与句末**拖长号**（如「为什么移开视线呢━━━？」）。**一律原位保留，不得替换为省略号、不得删除**
2. **三套括号各司其职，不可互换**：对白 `「」`／内引·复述 `『』`／概念·强调 `【】`

6. **尾音分工不可互换**：紫乃「ぁ/呀」轻柔／朱奈「～」语速慢／樱月「！」强语气
7. **页脚引流语必须逐字译出，不得漏译或删**：`【フォローする】`→【关注】／`【作品ページ】`→【作品页】／`【レビュー】`→【评论】／`【★で称える】`→【用★称赞】／`【⊕】`

10. 颜文字/符号：001-017 未出现；033 有 ♡/♪、034 有 ☆ → 保留原有，**不得新增**
